Mend Video Factory — Web

Mend Video Factory is a local, script‑driven video generation tool that takes your narration audio (voice.wav), optional script text (script.txt), and a set of images (or video clips), then automatically builds a finished 1080p MP4 with background music, Ken Burns-style motion, and subtitles (SRT + optional burned‑in subtitles) using FFmpeg.

Tip: for cloned-voice TTS you only need to save a voice profile once, then paste text + upload images.
